# 超市售货管理系统 (Supermarket System)

基于 Python PyQt6 开发的轻量级桌面端超市收银与管理软件。支持商品管理、扫码收银、库存监控及销售数据可视化分析。
## 更新日志
1. shop-sys.v1.0 (2025-12-20) 完成系统的基础开发
## ✨ 主要功能
* **🔐 安全登录**: 管理员身份验证。
* **📦 商品管理**: 支持商品的录入、修改、删除及库存查询。
* **💰 收银台**: 模拟扫码枪输入，支持购物车结算，自动扣减库存。
* **📊 数据报表**: 按日期范围生成可视化的销售趋势图 (柱状图)。
* **🚀 便携部署**: 可打包为绿色版 EXE，无需安装 Python 环境。

## 🛠️ 环境依赖 (开发模式)
如果你想修改源代码，请确保安装以下环境：
* Python 3.10 或更高版本
* 依赖库:
    ```bash
    pip install -r requirements.txt
    ```

## 🚀 快速开始

### 1. 首次运行与初始化
首次运行程序会自动检测数据库。如果 `shop.db` 不存在，系统会自动创建并生成默认管理员账号。

**默认管理员账号:**
* 用户名: `admin`
* 密码: `admin`

### 2. 运行源代码
```bash
python main.py

```

### 3. 打包为 EXE (Windows)

如果你需要将其部署到其他电脑上：

1. 在终端执行打包命令：
```bash
pyinstaller --noconsole --onefile --name="SupermarketSystem" --clean main.py

```


2. 等待打包完成（约 1-3 分钟）。
3. 在生成的 `dist/` 文件夹中找到 `SupermarketSystem.exe`。
4. **注意**: 将 EXE 移动到任何位置运行时，它会在同目录下生成/读取 `shop.db` 数据库文件。

## 📖 使用指南

### 商品录入

1. 进入“商品管理”页面。
2. 点击“新增商品”。
3. 输入条码（支持扫描枪输入）、名称、进价、售价及初始库存。

### 收银操作

1. 进入“收银台”页面。
2. 点击输入框，使用扫码枪扫描商品条码（或键盘输入并回车）。
3. 商品会自动加入列表，重复扫描可增加数量。
4. 点击“确认结算”完成交易，系统自动扣库存。

### 查看报表

1. 进入“销售报表”页面。
2. 选择开始日期和结束日期。
3. 点击“生成报表”查看销售额走势。

## ⚠️ 常见问题

* **图表中文乱码**: 系统默认使用 `SimHei` 字体。如果系统未安装该字体，请修改 `ui/stats_page.py` 中的字体设置。
* **数据丢失**: 请勿随意删除与 EXE 同目录下的 `shop.db` 文件，那是你的所有数据！
