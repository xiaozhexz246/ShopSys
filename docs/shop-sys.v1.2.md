# 更新日志 (Changelog)

本文档记录超市售货系统的所有重要变更。

---

## [v1.2] - 2025-12-20

### ✨ 新增功能

#### 商品管理
- **商品类别管理**
  - 新增 `category` 字段,支持商品分类
  - 预设类别: 香烟、酒水、饮料、零食、日用品、未设置
  - 支持自定义添加新类别

- **存放位置管理**
  - 新增 `location` 字段,记录商品存放位置
  - 预设位置: 一楼、二楼、楼梯、未设置
  - 支持自定义添加新位置

- **商品搜索功能**
  - 在商品管理页面新增搜索栏
  - 支持按商品名称模糊查询
  - 实时搜索,即输即查

- **进价显示控制**
  - 新增"显示/隐藏进价"切换按钮
  - 默认隐藏进价列,保护敏感信息
  - 按钮状态可视化(低饱和度/正常饱和度)

#### 收银台
- **实付金额功能**
  - 购物清单新增"实付金额"列
  - 默认等于商品售价,可手动调整
  - 价格范围限制: 进价 ≤ 实付金额 ≤ 售价
  - 小计自动根据实付金额计算

- **销售记录优化**
  - 销售记录使用实付金额而非原售价
  - 支持折扣销售的准确记录

#### 用户体验
- **登录界面改进**
  - 用户名输入框支持回车键快速登录
  - 密码输入框支持回车键快速登录
  - 无需鼠标点击,提高操作效率

### 🔧 改进优化

- **新增商品窗口**
  - 窗口高度调整为 350px,适应新字段
  - 使用可编辑下拉框,兼顾预设和自定义

- **商品管理表格**
  - 列数从 5 列扩展为 7 列
  - 动态调整列显示(根据进价显示状态)

- **数据库模型**
  - Product 模型新增 category 和 location 字段
  - 默认值设为"未设置",避免空值

### 🛠️ 技术更新

- **service 层**
  - `ProductService.add_product()` 支持新参数
  - `SaleService.checkout()` 使用实付金额计算

- **文档完善**
  - 新增升级指南 ([upgrade-guide.md](docs/upgrade-guide.md))
  - 新增测试清单 ([test-checklist.md](docs/test-checklist.md))
  - 新增升级脚本 (`upgrade_db.py`)

## [v1.0] - 2025-12-20

### ✨ 首次发布

#### 核心功能

- **用户管理**
  - 管理员登录验证
  - MD5 密码加密

- **商品管理**
  - 商品增删改查
  - 库存管理
  - 条码支持

- **收银功能**
  - 购物车管理
  - 扫码添加商品
  - 库存扣减
  - 交易事务处理

- **数据统计**
  - 销售记录查询
  - 数据可视化图表

#### 技术架构

- **前端**: PyQt6
- **后端**: Python 3.10+
- **数据库**: SQLite + SQLAlchemy ORM
- **分析**: Pandas + Matplotlib
- **部署**: PyInstaller

## 版本命名规则

- **主版本号** (Major): 重大架构变更或不兼容更新
- **次版本号** (Minor): 新增功能
- **修订号** (Patch): Bug 修复和小优化

格式: `v主版本.次版本.修订号` (例: v1.2.0)
