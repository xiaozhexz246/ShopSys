# 超市售货系统 v1.5 升级任务清单 (Todo List)
## 新增功能
1. 商品增加属性：生产日期，保质期，在新增商品时，默认为0，即不设置。

3. 新增“进货”标签页，上下分栏设计，上面为搜索结果显示区域，下面为待进货区。
- 可以对商品名称模糊查询或扫条形码查询编号，上面的搜索显示区域显示商品名称、类别、进价、售价、库存量，和“进货按钮”，点击后把商品条目添加到下面的待进货区。
- 待进货区的每个条目包含商品名称、类别、新增数量，其中用户可以填写新增数量，其余信息复用上面的搜索结果。
- 在待进货区下方设置一个“确定”按钮，用户进货完成后点击确定按钮，商品信息批量写入数据库，更新库存量，并提示成功。

针对商品过期问题，应该孤立出来，即设置一个单独的表，保存能过期的商品信息，商品按照编号和生产日期分类，定时检查是否有商品过期，并提示。
4. 新增“过期商品监测”标签页，上下分栏设计，上面为搜索结果显示区域，下面为待修改区。
- 可以对商品名称模糊查询或扫条形码查询编号，上面的搜索显示区域显示商品名称、类别、总库存量和一个下拉框箭头，点击箭头后，展示该商品下的所有的生产日期、过期时间、库存量及序号条目和“修改数量”按钮，序号按照生产日期的时间排序，点击修改按钮后把商品条目添加到下面的待修改区。
- 待修改区的每个条目包含商品名称、修改后数量，生产日期，输入框，其中用户可以修改“修改后数量”，其余信息复用上面的搜索结果。
- 在待修改区下方设置一个“确定”按钮，用户修改完成后点击确定按钮，批量修改数据库内的商品库存信息，更新库存量，并提示成功。如果待修改区的商品数量为0，则删除该商品条目。
