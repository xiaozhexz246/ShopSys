# 超市售货系统 v1.5 升级任务清单 (Todo List)
## 新增功能
1. 新增“进货”标签页，上下分栏设计，上面为搜索结果显示区域，下面为待进货区。
- 可以对商品名称模糊查询或扫条形码查询编号，上面的搜索显示区域显示商品名称、类别、进价、售价、库存量，和“进货按钮”，点击后把商品条目添加到下面的待进货区。
- 待进货区的每个条目包含商品名称、类别、新增数量，其中用户可以填写新增数量，其余信息复用上面的搜索结果。
- 在待进货区下方设置一个“确定”按钮，用户进货完成后点击确定按钮，商品信息批量写入数据库，更新库存量，并提示成功。
- 同时优化出售逻辑：当商品出售，数量为0时，不删除商品条目，因为进货时会增加条目。
2. 在商品管理界面，增加商品编辑功能
3. 针对商品过期问题，应设置一个单独的过期商品表，保存能过期的商品信息，和新增的属性：生产日期，保质期；商品按照编号、名称和生产日期分类，定时检查是否有商品过期，并提示。
- 新增“易过期商品管理”标签页，复用商品管理界面逻辑，可以实现易过期商品的增删改查
- 在新增商品时，我希望能和已有的商品数据库和过期商品数据库联动，输入商品编号可以检索，或根据名字进行模糊搜索，把已有商品信息填入到对应的文本框中，用户只需再填写生产日期和保质期。如果商品已存在于过期商品数据库中，保质期都可以自动填充到对应的文本框中。
