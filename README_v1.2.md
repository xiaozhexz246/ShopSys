## 🚀 快速开始

### 首次安装

```bash
# 1. 初始化数据库
python init.py

# 2. 启动系统
python main.py

# 3. 默认账号登录
用户名: admin
密码: admin
```

### 从 v1.1 升级

```bash
# 1. 备份数据库(重要!)
copy shop.db shop_backup.db

# 2. 运行升级脚本
python upgrade_db.py

# 3. 启动系统
python main.py
```

## ✨ v1.2 新功能亮点

### 1️⃣ 商品分类与定位

- **商品类别**: 香烟、酒水、饮料、零食、日用品等

- 在商品管理页面的搜索框输入商品名称

- 默认隐藏商品进价,保护商业机密

- 收银台新增"实付金额"功能
- 支持临时折扣和议价
- 自动限制价格范围(进价~售价)

### 5️⃣ 快捷登录

- 用户名和密码框均支持回车键登录
- 无需鼠标操作,提高效率

## 🎯 核心功能使用

### 商品管理

#### 添加商品
1. 进入"商品管理"页面
2. 点击"➕ 新增商品"
3. 填写信息:
   - 商品编号(条码)
   - 商品名称
   - **商品类别**(新)
   - **存放位置**(新)
   - 进货价
   - 零售价
   - 库存量
4. 点击"确定"

#### 搜索商品
- 在页面顶部搜索框输入商品名称
- 支持拼音首字母或部分名称

#### 切换进价显示
- 点击"显示进价"按钮
- 按钮变绿色,表格显示进价列
- 再次点击隐藏

### 收银台操作

#### 方式1: 扫码添加
1. 在"扫码枪输入"框输入商品编号
2. 按回车
3. 商品自动添加到购物车

#### 方式2: 搜索添加
1. 在搜索框输入商品名称
2. 点击"搜索"
3. 调整数量
4. 点击"➕ 添加"

#### 调整实付金额
1. 在购物车的"实付金额"列
2. 使用数字调节器修改价格
3. 小计和总金额自动更新

#### 结算
1. 确认购物清单
2. 点击"确认结算"
3. 二次确认后完成交易

## 🔧 数据库说明

### 新增字段

**products 表**:
- `category` (TEXT): 商品类别,默认"未设置"
- `location` (TEXT): 存放位置,默认"未设置"

### 数据迁移

**如果您有旧数据**:
```bash
# 使用升级脚本(推荐)
python upgrade_db.py

# 或手动SQL
ALTER TABLE products ADD COLUMN category TEXT DEFAULT '未设置';
ALTER TABLE products ADD COLUMN location TEXT DEFAULT '未设置';
```

**如果是全新安装**:
```bash
# 删除旧数据库
del shop.db

# 重新初始化
python init.py
```

## 📝 常见问题

### Q: 升级后旧商品的类别和位置显示什么?
**A**: 显示"未设置"。您可以手动编辑这些商品来更新信息。

### Q: 实付金额可以随便改吗?
**A**: 不可以。系统限制实付金额必须在进价和售价之间。

### Q: 如何恢复到旧版本?
**A**:
1. 关闭系统
2. 删除 shop.db
3. 重命名备份文件 `shop_backup.db` 为 `shop.db`
4. 使用旧版本代码启动

### Q: 能否批量导入商品类别?
**A**: 当前版本不支持。您可以在添加商品时逐个输入,系统会记住输入过的类别。

### Q: 搜索功能区分大小写吗?
**A**: SQLite 默认不区分大小写(对 ASCII 字符)。
